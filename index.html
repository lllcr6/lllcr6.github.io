RAG-Powered Documentation Q&A

Built an end-to-end Retrieval-Augmented Generation (RAG) system for answering questions about RapidFire AI documentation with grounded, source-cited responses. The system combines BM25 keyword search with dense embedding retrieval through Reciprocal Rank Fusion, followed by cross-encoder reranking to improve retrieval relevance.

I also designed validation Q&A pairs and an evaluation pipeline covering retrieval precision, recall, F1, and LLM-judged answer quality. Through controlled experiments on chunk size, reranking thresholds, and reranker models, the best configuration achieved a retrieval score of 0.7699 using MiniLM-L12-v2.

Memory-Efficient Micro-UAV Navigation

An embedded autonomous navigation system for resource-constrained micro-UAVs using C and FreeRTOS. The system combines LiDAR-based 3D occupancy mapping with RRT* path planning, and uses a custom linear memory pool plus a compact 16-bit octree node representation to reduce memory overhead. The project also contributed to a granted Chinese invention patent (CN116499464B).
